STINGER TRANSITION (RECORD ME)

          

            A 1-second collapse→burst loop. Screen-record it into an MP4, then load that MP4 in OBS as a Stinger Transition for cinematic scene cuts.
          

          

            
            
            
          

          

            URL: 
          

          

            How to record it for OBS
            
    
              
  1. Click Preview Stinger above. It opens a new tab with the looping animation.
    2. 
              
  2. On Windows: press Win + Alt + R to start Game Bar recording. Or use OBS itself: add a Browser Source with the stinger URL, hide everything else, hit Start Recording.
    3. 
              
  3. Let it record for about 3 seconds (captures 3 loops). Stop.
    4. 
              
  4. Open the resulting MP4 in any video editor (Clipchamp, DaVinci Resolve, ffmpeg). Trim to one clean cycle — exactly 1000ms (or 700/1400 if you used Fast/Slow).
    5. 
              
  5. In OBS: Settings → Scene Transitions → click + → Stinger → load your trimmed MP4.
    6. 
              
  6. Set Transition Point to 500ms (the midpoint where OBS swaps scenes under the flash).
    7. 
              
  7. Set as your default transition. Done — every scene cut now plays the stinger.
    8. 
            

          


          

            
            
            (or use SAVE ALL CHANGES at the bottom — covers everything)
